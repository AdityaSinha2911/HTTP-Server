# C++ HTTP Server from Scratch

A web browser cannot understand your C++ program directly—it communicates using the **HTTP (HyperText Transfer Protocol)**. An **HTTP server** is the software that listens for HTTP requests (such as opening a website), processes those requests, and sends back an HTTP response containing a webpage, image, JSON data, or any other content. The goal of this project is to build an HTTP server completely from scratch in **C++**, without using any web frameworks, so I can understand how web servers work internally—from low-level socket programming to request parsing, response generation, and eventually serving complete websites.

> **Project Status:** 🚧 In Progress  
> This repository documents my journey of building a fully functional HTTP server step by step.

---

# 🚀 Current Progress

The following features have been implemented so far:

- ✅ Create a TCP IPv4 socket using `socket()`
- ✅ Bind the server to a local port using `bind()`
- ✅ Listen for incoming client connections using `listen()`
- ✅ Accept client connections using `accept()`
- ✅ Receive raw HTTP requests using `recv()`
- ✅ Print incoming HTTP requests to the terminal
- ✅ Manually construct a valid HTTP response
- ✅ Send HTTP responses using `send()`
- ✅ Serve a basic HTML page in the browser
- ✅ Handle client disconnection
- ✅ Properly close sockets and clean up resources

# ⚙️ Prerequisites

Install the required packages:

```bash
sudo apt update
sudo apt install build-essential g++ gdb valgrind
```

---

# 🔨 Compile

Using g++:

```bash
g++ main.cpp -o server
```

Or using Makefile:

```bash
make
```

---

# ▶️ Run

Start the server:

```bash
./server
```

You should see something similar to:

```text
Socket Created, socket FD: 3
Binding Successful
Listening
```

---

# 🌐 Test the Server

Open your browser and visit:

```text
http://localhost:8081
```

or

```text
http://127.0.0.1:8081
```

The browser will receive a simple HTML response generated by the server.

You can also test using Netcat:

```bash
nc 127.0.0.1 8081
```

# 📥 Example HTTP Request
